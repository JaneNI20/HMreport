移动空调用户分群与场景框架

把六类用户从“画像标签”还原为可评审的购买任务、具体场景与旅程摩擦：他们为什么买、在什么条件下被触发、现有方案哪里失效，以及这些证据可能指向哪些产品机会。

本页用于校准与讨论；研究证据、综合推论与待验证假设明确分开。
会议不是要立刻定六条产品线

先确认购买任务是否成立、边界是否清楚、痛点是否重要；再讨论哪些需求应该由平台、系列、SKU、配件、服务或传播表达承接。用户分群 → 产品机会，不等于 用户分群 → 产品线。

先判断任务，再讨论人群

人群标签是识别和讨论的入口；购买任务才是跨场景、跨生命周期可复用的组织方式。

同一人可以跨任务迁移

一个用户可能今天是独立空间温度控制，热浪时成为应急备用，家庭阶段变化后又转向守护需求。

产品机会不等于产品线

一个平台或一个 SKU 可以覆盖多个任务；不同需求也可能通过配件、引导、渠道或服务来解决。

02 / 人群地图

六类用户的概念象限：看清共同点、差异与尚未覆盖的空间

这是基于购买动机、使用节奏和场景的研究综合定位，用于比较，不是统计分析或精确坐标。点击任一人群可查看该类样本的人口学与家庭背景分布。

方向性综合推论
更日常 / 持续的使用关系 更事件触发 / 需要时使用 个人舒适与自主 家庭保障与生活约束 个人温控、工作与睡眠状态 照护、共处与居住现实 即时缓解、局部快速见效 故障、热浪与风险兜底

如何解读

纵轴看用户与产品的使用关系：是长期持续的舒适管理，还是由热浪、故障或特定高温事件触发。

横轴看价值重心：是个人对体感的掌控，还是家庭照护、共同生活或空间条件带来的约束。

  • 同一人可能因家庭阶段或天气，在象限间迁移。
  • 相近位置不代表可以合并；仍需回到任务、需求模式 与痛点判断。
  • 若未来出现明显的空白区域，可能提示尚未被当前六类覆盖的购买任务。
各点位置来自 基于研究的综合推论；点的大小不代表市场规模，颜色与六类人群卡一致。
03 / 共同体验底线

画像与旅程先聚焦“为何重要”，不以人口学替代分群

参考框架中的“谁、何时何地、痛点与目标”已被纳入本页；但人口学只作为辅助描述，不作为六类定义或产品规划的直接依据。

阅读说明

大户型卧室访谈提出的四项共性体验底线

好装非标窗、排气与密封不能把“开箱即用”变成被迫 DIY。
好养排水、滤网、收纳和搬动一旦麻烦，就会成为持续性负担。
好睡夜间噪音、灯光、盲操与温度波动影响睡眠或专注。
能耗可控用户需要省电策略、可理解的能耗反馈，或至少降低账单不确定性。

证据使用边界

研究证据 定量报告中的比例、痛点分数、场景和动机；访谈中明确出现的人物、行为、原话与旅程摩擦。

基于研究的综合推论 把跨材料的动机、场景和痛点整理为“未满足需求”。

假设 / 待验证 产品能力、付费意愿、战略价值、系列或 SKU 规划，均需 PM 与后续研究共同验证。

小户型访谈材料被用作“受限空间平衡型”的补充定性参照，不新增第七类人群，也不改变六类的定量定义。
04 / 品牌长期空间

从移动空调，走向个人睡眠与工作舒适解决方案

以下三项来自品牌长期方向，用于把当前的购买任务放到更长周期的价值空间中。它们不是本轮六类人群研究直接验证出的新结论。

品牌长期方向
品牌长期方向 · 非本轮研究证据

不只销售一台制冷设备，而是在关键房间、关键时段帮助用户获得更可控的睡眠与工作舒适。

这里的作用是提出未来值得验证的价值方向，并连接既有用户任务；不能据此新增人群、重定义六类分群，或直接推出产品线结论。
长期方向

睡眠科技（SleepTech）

把“能降温”升级为对深睡眠和夜间安心的可感知支持，温度、湿度、静谧感等体验都值得进入未来验证。

当前研究锚点 家庭健康守护型中，改善炎热环境下睡眠为 71.9%，夜间睡眠场景为 70.3%；Sarah 的访谈也将“让孩子整夜安睡”呈现为核心结果。
长期方向

居家办公（WFH / Home Office）

当工作与居住交叠，关键房间的舒适度会影响专注与生产力；局部、低干扰的舒适管理可能成为长期价值场景。

当前研究锚点 空间自主掌控型中，特定房间控制权为 52.8%，居家办公舒适为 40.4%；David 的访谈显示，高温会直接影响工作与睡眠。
长期方向

个性化室内微气候（Personal Micro-Climate）

从“一人开机、全屋降温”转向按人、按房间、按时段提供更贴合体感的局部舒适，是智能家庭中的潜在平台方向。

当前研究锚点 特定房间控制权为 52.8%，只冷目标空间为 54.9%；P22 显示移动空调常被放在既有中央空调或窗机未覆盖好的关键空间中补位。
重要原则：三大趋势不等于三条产品线。它们是跨人群、跨购买任务的长期价值方向；产品平台、系列、SKU 的承接方式，仍要经过任务真实性、技术可行性、价格与支付意愿验证。
05 / 六类用户

六类定义：每类都从购买任务走到未满足需求

06 / 关键边界

六类不是六个互不相交的“人”，而是有边界的购买任务组合

PM 重点不是判断名字好不好听，而是判断任务、动机、场景、关键痛点与预期结果是否足够不同，值得保留为独立的讨论单元。

建议重点讨论

空间自主掌控型 vs 局部速冷控温型

共同：都在解决关键房间补冷，尤其是强日晒或主空调覆盖不足。

区分：前者追求长期、可掌控的个人舒适；后者更强调“现在很热，尽快有效”的即时结果。

当前判断：保留为购买任务 01 下的两个需求模式，验证是否存在不同技术、价格或传播需求。

便捷安居实用型 vs 有限空间平衡型

共同：都重视低操作成本、安装便利与现实居住约束。

区分：前者核心是“少麻烦、灵活可用”；后者核心是设备进入生活空间后的持续共处，包括噪音、占地、排水与电路压力。

当前判断：前者偏体验流程，后者偏空间约束；是否需要独立平台尚未确认。

家庭健康守护型 vs 理性应急准备型

共同：都可能是为家人买单，也都会强调安心和可靠。

区分：前者是日常、高频的照护与睡眠任务；后者是低频、极端场景的风险管理与备用保障。

当前判断：使用频率、触发机制、性能容忍与长期价值不同，建议保留为独立任务。

09 / 典型用户与旅程证据

两条已有深度访谈支撑的典型旅程

人物不是用来替代分群，而是让 PM 看见：动机如何在“触发—寻找—安装—使用—维护”的连续过程中变成具体摩擦。这两条只代表已访谈到的典型案例，不能被视为该类所有用户的定量比例。

定性证据

Sarah · 家庭健康守护型

45 岁女性；大户型老房，中央空调覆盖不到二楼儿童房。角色：“首席舒适官”。

“为了孩子能睡个好觉，我可以忍受所有的不便。”访谈 典型用户原话 / 大户型卧室用户研究
触发

二楼卧室闷热，孩子无法入睡；把全屋中央空调调低又会让其他人太冷、账单上升。

寻找

依赖线下卖场、评价和“适用面积”信息；追求立即可得，不想让孩子再多熬一个热夜。

安装

窄窗或异形窗让标配窗套失效，需要胶带、泡沫或其他 DIY 密封；设备搬上楼也很吃力。

使用

夜间开启约 75°F；孩子睡着后，半夜再进房间调节或关机，在舒适、着凉担忧和电费之间取平衡。

维护

电费、滤网和排水成为持续的心理与操作负担；满意度取决于孩子是否整晚安睡，而不是机器参数本身。

假设 / 待验证
可优先验证：非标窗“到手即装”、夜间温控与低打扰、可理解的能耗引导，是否能显著降低“责任与电费”之间的焦虑。

David · 空间自主掌控型

38 岁男性；居家办公者，住宅存在西晒或加建区域，追求个人房间温度主权。

“如果我热得出汗，我就睡不好，生活质量也会下降。”访谈 典型用户原话 / 大户型卧室用户研究
触发

高温影响睡眠和工作效率；与家人存在体感差异，中央空调无法让他的目标房间达到理想温度。

寻找

深度研究 Reddit、Google、Amazon 和 BTU 信息，关注真实性能、降温速度、噪音和智能控制。

安装

愿意自己处理排气管、密封与摆位，但对软管僵硬、占地和物流损坏容忍度低。

使用

倾向最低温度加最高风速，追求进屋即凉；开会或睡眠前再降低功率，试图绕开风噪和灯光干扰。

维护

排水、漏水风险、夜间指示灯和噪音不断打断“设好就忘”的理想体验。

假设 / 待验证
可优先验证：高温速冷与稳定控温的真实表现、低干扰夜间体验、预冷与能耗反馈，是否支撑对高客单和智能功能的支付意愿。

其余四类：先保留为“待验证旅程假设”，不要伪装为已完成定性画像

便捷安居实用型可验证“从购买到安装是否一气呵成”；局部速冷控温型可验证“高温下为什么现有制冷失效”；有限空间平衡型可验证“噪音、占地、排水与电路约束如何共同影响使用”；理性应急准备型可验证“存放、启动和兼容性如何决定关键时刻的信任”。

需要补访谈 / 日记研究 / 售后与评论证据 不新增或重聚类六类人群

规划原则：“好装、好养、好睡、能耗可控”更接近跨人群的体验底线；只有当某项需求在任务独特性、市场价值、支付意愿和公司能力上都被证实时，才值得进一步讨论是否形成独立系列或 SKU。
11 / PM 评审框架

PM 需要做的不是“喜欢哪个画像”，而是留下可执行判断

每一类可独立评分，也可以先对五个首要购买任务做第一轮判断。名称、边界和逻辑都允许会后调整，但每次调整必须保留理由与证据缺口。

会议产出

真实性 · 差异性

先判断任务是否真实存在，及其是否值得与其他类型分开。

  1. 你在销售、评论、售后、渠道或自身用户中见过这个任务吗？
  2. 它的触发、动机和期待结果是否清楚？
  3. 与哪一类重叠？重叠的是场景、痛点还是购买动机？

重要性 · 产品机会

判断需求存在之外的市场与产品意义。

  1. 它代表规模、增长、利润、品牌还是战略防御价值？
  2. 痛点能否转成可定义、可验证的产品能力？
  3. 是否需要新技术，还是改进现有体验、配件或导购即可？

战略匹配度 · 优先级

明确由谁服务、何时服务，而不是把所有需求都变成当年项目。

  1. 是否符合公司的技术积累、供应链、渠道和品牌方向？
  2. 近期：近期规划必须处理；下一步：补证据后投入；未来：保留观察。
  3. 最合适的承接方式是平台、系列、SKU、配件、服务还是传播？

证据缺口

所有判断都要说明依据与待补研究，尤其要区分业务经验和研究事实。

  1. 还缺市场规模、场景频率、支付意愿、渠道数据还是技术可行性？
  2. 哪些结论应从“综合推论”降级为“待验证假设”？
  3. 后续优先补访谈、量化验证、评论/售后分析还是概念测试？

13 / 证据与研究缺口

哪些已有证据，哪些还不能替代产品决策

当前研究足以支持购买任务、动机、场景和痛点的初步框架；但还不足以单独决定产品线数量、SKU 数量或投资优先级。

待验证

分群研究缺口

需确认六类是否稳定、可识别，及边界是否需要调整。

  • 六类之间的真实重叠与用户迁移路径。
  • 空间自主掌控型与局部速冷控温型是否应长期共享 购买任务 01。
  • 用户是否能以购买任务而非研究标签描述自己的需求。
  • 不同地区、房型、家庭阶段下，任务重要性是否变化。

业务验证缺口

需确认哪些任务值得投入，而不仅是需求真实存在。

  • 市场规模、场景频率、销售转化和利润贡献。
  • 价格接受度、支付意愿及功能溢价空间。
  • 各任务的渠道可触达性与区域机会。
  • 哪些人群代表增量，哪些主要承接既有需求。
  • 睡眠科技、居家办公与个性化室内微气候三项长期方向的发生频率、跨人群适用范围与溢价空间。

产品定义缺口

需把痛点转化为明确的能力和体验指标。

  • 速冷与稳定控温是否确实需要不同技术能力。
  • 各任务对制冷、噪音、能耗、安装和排水的最低门槛。
  • 哪些需求可由同一平台覆盖，哪些需结构或配件差异。
  • “好装、好养、好睡、能耗可控”中哪些是必须底线。

证据质量边界

需要保留样本与方法边界，避免过度解读。

  • 六类聚类主要来自约 n=380 样本；各类 n=39–89。
  • P22 潜在用户分析基数为 n=191，5/6/7 分分别为 n=84/58/49。
  • P23 TGI 使用现有与潜在用户总基数 n=391。
  • TGI 是相对集中度，不等同于市场规模；小样本细分只作方向参考。
