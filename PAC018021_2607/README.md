# 移动空调概念测试（PAC018&P021）

这个文件夹是从单文件 HTML 拆出的可编辑版本。

## 怎么浏览

直接打开 `index.html`，或上传到 GitHub Pages / 内部静态服务器后访问 `index.html`。

## 怎么编辑

- 主导航和页面顺序：编辑 `index.html` 里的 `pages` / `sections`。
- 单页内容：编辑 `pages/` 下对应的 HTML 文件。
- 页面文件已按真实页码命名，例如 `pages/P06.html` 对应第 6 页。

## 注意

- 不要用格式化工具美化整份 `index.html`，保持现有结构更稳。
- 如果上传到 GitHub Pages，整个文件夹内容需要一起上传，不能只上传 `index.html`。
